# SudfryTodo · iPhone / iPad 待办 + 记账（单文件网页应用）

一个 **单文件** 的 PWA：`SudfryTodo.html`。里面 HTML、CSS、JS 全部内联，
**不引用任何外部资源、CDN、图片或字体，也不发任何网络请求**。
数据存在浏览器本机的 `localStorage` 里。

- 主文件：[SudfryTodo.html](SudfryTodo.html)（约 114 KB）
- 适用：iPhone / iPad 的 Safari；Chrome、Edge、Android 浏览器同样可用
- 无需安装、无需联网、无需服务器

---

## 一、安装到 iPhone / iPad 主屏幕

1. 把 `SudfryTodo.html` 传到手机上（AirDrop、iCloud Drive、微信文件传输助手、邮件附件都行）。
2. 用 **Safari** 打开这个文件（点开文件后选「用 Safari 打开」；放在「文件」App 里时，
   可以长按 → 共享 → 在 Safari 中打开）。
3. 点 Safari 底部的 **分享按钮** → **添加到主屏幕** → 命名 → 添加。
4. 从主屏幕图标进入，就是一个全屏运行、没有地址栏的应用，**完全离线可用**。

> 也可以把文件放到任意静态服务器上再访问，效果一样；
> 但离线可用性来自「单文件本身」，**没有使用 Service Worker**（file:// 下 SW 不可靠，
> 单文件反而更稳）。

图标是内联的 SVG data-URI：**深蓝底 + 日历 + 绿色勾 + 紧急红点**，与 Android 版一致。

## 二、待办部分

### 三个视图（底部标签切换）

**今天**
- 概览卡：「今天要处理 N 项」+ 已完成 x/y + 进度条 + `已逾期 / 今天 / 3 天内` 彩色徽章 + 本周完成数
- **需要马上处理**：所有逾期任务置顶，整条红色描边
- **24 小时时间轴**：06:00 起画（当天有更早任务会自动提前），任务按起止时间画成色块，
  颜色 = 紧急度，**重叠任务自动分列**，当前时刻一条红线 + 圆点 + 「现在」标签；点色块进编辑，
  点空白处按该时刻新建任务
- **不限时间**：当天只填了日期没填时刻的任务
- **今日账目卡**：今日支出 / 每日预算 / 剩余（超支变红）+ 进度条 + 今日流水

**日历**
- 月视图，每格显示：日期、最多 3 条**紧急色条**、`+N`、以及当天收支净额的小字
  （绿色 `+¥120`、红色 `-¥38.5`、收支都有时显示 `±¥净额`）
- 今天实心圆，选中日有底色，周末表头变色；↑↓ 切月，「今天」一键回到本月
- 点某天，下方（宽屏时右侧）列出**当天任务 + 当天收支**，并有「＋任务 / ＋记一笔」按钮

**全部**
- 自动分组：`已逾期 / 今天 / 明天 / 3 天内 / 以后 / 无期限 / 已完成`
- 关键词搜索（标题 / 备注 / 分类）、分类筛选、状态筛选、一键清除已完成（带确认、可撤销）

### 任务字段
标题、备注、分类标签、截止日期、可选具体时刻、预计时长、优先级（低/中/高/紧急）、
重复（不重复/每天/每周/每月）、提醒（不提醒/准时/5/10/30 分钟前/1 小时前/1 天前）、完成状态。
**重复任务勾选完成后自动生成下一期**（并提示下一次的日期）。

### 紧急度配色（贯穿全应用，不受主题色影响）

| 档位 | 颜色 | 判定 |
|---|---|---|
| 已逾期 | 红 `#E5484D` | 日期已过，或今天但指定时刻已过 |
| 今天 | 橙 `#F76B15` | 就是今天 |
| 临近 | 黄 `#D99A00` | 明天 / 后天 |
| 以后 | 绿 `#2F9E62` | 3 天及以后 |
| 无期限 | 灰 `#8A8F98` | 没有截止时间 |

同时给出文字倒计时：`已逾期 1 天`、`还剩 3 小时 36 分`、`今天内完成`、`明天到期`。
只填日期不填时刻的任务**不会**被报成「还剩几分」，而是「今天内完成」。
排序：未完成在前 → 逾期最前 → 优先级高在前 → 时间早在前。

### 任务操作
**长按任务行**（或点行尾的 `⋯`）弹出：编辑 / 标记完成 / 推迟到明天 / 推迟 1 小时 / 复制 / 删除。
删除后底部出现「已删除「X」 **撤销**」，**6 秒内可恢复**。

## 三、记账部分

**记一笔**
类型（支出/收入）、金额（大号数字键盘 `inputmode=decimal`）、**二级分类**（大类 → 小类，
用需求给定的分类表，含「自定义」可自行输入小类）、备注、**重点星标**、
支付平台（银行卡/微信/支付宝/现金/校园卡，点「＋ 新增」可自行扩展）。

**每日预算**
可设置每日预算金额；在「今天」页显示 今日支出 / 每日预算 / 剩余，配进度条，**超支变红**，
文案从「剩余」变成「超支」。

**当日收支流水**
`‹ 日期 今天 日期 ›` 切换日期，列出当天收入与支出，**每条可单独删除**（可撤销），
顶部给出当天收入 / 支出 / 净额。

**月度结算**
选年份与月份、填「月生活费」、勾选纳入结算的支出分类（**勾大类 = 全选其下小类**），
实时显示 **月收入 / 选定支出 / 生活费剩余** 三个数字。

**分类分析**
按月或按年、支出或收入、按金额或名称、升序或降序，
用**横向条形图**展示各分类金额、条形长度与**占比百分比**；点分类前的箭头可展开看小类构成。

## 四、设置

- **明暗模式**：浅色 / 深色 / 跟随系统（`prefers-color-scheme` 变化会实时跟随）
- **主题色自定义**：色相滑块（0–360）+ 饱和度滑块（0–80），实时预览，
  另有 8 个预设色点。**主题色只作用于强调色**（按钮、选中态、悬浮按钮、日历「今天」、进度条），
  **紧急度五色与收入/支出色始终不变**
- **音效**：开关 + 音量滑块 + 4 种音色（柔和 / 清脆 / 低沉 / 轻点），
  全部由 **Web Audio 现场合成**，没有任何音频文件。iOS 上 AudioContext 必须由用户手势解锁，
  代码在第一次 `touchstart`/`mousedown` 时创建并 `resume()`，并带「试听一下」按钮
- **数据**：
  - 导出备份（下载 `.json` 文件）
  - 从文件导入（选择文件）
  - 粘贴文本导入
  - 复制全部数据到剪贴板
  - 清空全部数据（带确认 + 可撤销）
  - 导入时可选择 **合并**（默认，按 `uid` + `updatedAt` 取新，不产生重复）或 **覆盖本机**

```json
{
  "app": "sudfry-todo",
  "version": 3,
  "exportedAt": 1791705915000,
  "device": "iPhone Safari",
  "items": [{
    "uid": "u...", "title": "给客户回复报价邮件", "note": "", "tag": "工作",
    "due": 1791706800000, "hasTime": true, "durationMin": 45,
    "priority": 3, "repeat": 0, "remindBefore": 10,
    "done": false, "doneAt": 0, "createdAt": 1791705000000, "updatedAt": 1791705000000
  }],
  "entries": [{
    "uid": "u...", "date": "2026-10-11", "type": "expense", "amount": 18.5,
    "category": "日常餐饮", "subcategory": "午餐", "note": "食堂",
    "important": false, "platform": "校园卡",
    "createdAt": 1791705000000, "updatedAt": 1791705000000
  }],

```

合并规则：同一 `uid` 视为同一条，**谁 `updatedAt` 新就用谁**；本机没有的就新增；
完全一样的不动（所以同一份备份反复导入不会重复）。缺少 `uid` 的老数据用
「标题 + 截止时间」指纹兜底判重。

`localStorage` 键名：`ribook3.todos`、`ribook3.entries`、`ribook3.meta`。

## 六、iOS / PWA 细节

- `<meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover">`
- `apple-mobile-web-app-capable` / `apple-mobile-web-app-status-bar-style` /
  `apple-mobile-web-app-title=SudfryTodo` / `theme-color`
- **状态栏样式在 `<head>` 里就按已保存主题设定好**（iOS 只在启动时读这个 meta，
  放在主脚本里改对本次启动无效）：浅色用 `default`（深色文字），深色用 `black-translucent`
- 全部内边距使用 `env(safe-area-inset-*)`，刘海与底部横条都不会遮住内容
- `apple-touch-icon` 为 180×180 的**内联 SVG data-URI**
- 触摸友好：`-webkit-tap-highlight-color: transparent`、按钮最小高度 ≥44px、
  无 hover 依赖、输入框字号 16px（防 iOS 自动放大）、长按元素加 `-webkit-touch-callout:none`
- 宽屏（≥900px）自动双栏：今天（左摘要 / 右时间轴）、日历（左月历 / 右清单）、
  全部（两组并列）、账本（左记账 / 右预算·结算·分析）；底部标签变成居中胶囊
- **不使用 Service Worker**：离线可用性由「单文件」保证

## 七、我怎么自检的（做了什么、没做什么）

  明天→soon、5 天后→later；倒计时文案 `今天内完成` / `已逾期 1 天` / `还剩 2 小时` /
  `已逾期 3 小时` / `明天到期`；分组 3 天内、已完成

- 记账：新增账目后重渲染、日历聚合、日历金额小字、分类分析（月/年、支出/收入）不抛异常、

- 同一份备份**重复导入不产生重复**；导入外部任务成功；非法 JSON 不崩

**3. 静态一致性检查（`_tmp/static.js`）**

  含 ≥900px 双栏媒体查询；没有 Service Worker 注册；关键触控控件都有最小高度

## 八、没能验证的地方（诚实说明）

1. **没有在真实 iPhone / iPad 上运行过**，也没有在真实 Safari 里打开过。
2. **没有在真实浏览器里渲染过**：我本机有 Edge，但无头模式被当前沙箱拦住

   真机触摸交互（长按、滚动、滑动手感）我都没有截图确认**。
   上面第 2、3 项检查只能证明「逻辑跑得通、类名与 id 都有对应定义」，**不能证明好看或好用**。
3. **「添加到主屏幕」的实际效果**（全屏、图标、状态栏配色、safe-area 留白）
   全部来自规范与常见做法，**没有在 iOS 上实测**。
4. **音效在 iOS 上是否真的解锁**：Web Audio 的解锁代码写在第一次
   `touchstart`/`mousedown` 上，逻辑正确，但**没有在 iOS 上听过声音**。
5. **提醒**只在应用打开时以页内提示条 + 提示音呈现。**iOS 的网页应用无法在完全关闭后弹系统通知**
   （那需要 Web Push + 服务器），这是平台限制，不是遗漏。
6. **导出下载**在 iOS Safari 上通过 `<a download>` + Blob，这在 iOS 13+ 可用，
   但**我没有在 iOS 上确认文件是否真的落到「文件」App**；如果失败，界面里还有
   「复制全部数据」这条退路。
7. 大额或极端数据（上千条任务、超长标题、跨 10 年的账目）没有压测过。
8. 深色模式下个别细节（阴影、色条对比度）没有肉眼确认过。

如果哪一项在你的设备上不对，把现象告诉我，我按现象改。
